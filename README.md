# Student-Management-System
This Student Management System is a beginner-friendly mini project built using Python and Object-Oriented Programming (OOP) concepts. It provides a simple command-line interface to manage student records within a school.

The project is designed to help beginners practice how OOP principles work in a real-world scenario. It lets users create student entries, update their information, delete records, categorize students by classes, and manage school-level data.

The system uses:
A Student class to store individual student details.
A StudentClass class to manage groups of students in the same class.
A class-level dictionary to store all student objects for quick access.
Menus to guide the user through various operations.

Key Learning Outcomes:
Understanding how class and instance variables work.
Using constructors (__init__) to set up object state.
Implementing methods to manipulate object data.
Managing class-to-object relationships (e.g., multiple students in one class).
Handling user input and dynamic data structures like lists and dictionaries.

This project is ideal for someone who has recently learned OOP in theory and wants to gain hands-on experience applying it.
